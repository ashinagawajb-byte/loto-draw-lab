# Site Analyzer 自動取込（GitHub Actions）

## 現在の状況
- GitHub側の取り込みプログラム・CSV検証・既存ファイル保護・スケジュールを設置済み。
- **Site本体の読み取り専用エクスポートAPIと認証設定は未確認／未設定**。そのため現時点では自動取込は稼働せず、GitHub Actionsは `SETUP_REQUIRED` を表示して安全に終了する。
- 一度固定した原本ファイルは上書きしない。同じ回の固定数字が変更されていたらエラーにする。

## Site側で必要な機能
1. 所有者専用の読み取りAPIで、**最後に固定されたロト6の5口**を返す。レスポンスは `text/csv; charset=utf-8`。形式：
```csv
回,口,数字1,数字2,数字3,数字4,数字5,数字6
2157,1,16,21,33,34,38,40
2157,2,5,14,24,32,35,43
2157,3,7,10,20,23,31,42
2157,4,1,3,4,6,27,37
2157,5,2,9,13,18,26,28
```
2. 固定後の保存済みスナップショットを返す。予想作業中の未固定5口は返さない。
3. 未固定のときは明確な `404` あるいは `204` を返す。生成途中や最新結果の予想を捏造しない。
4. サイトアクセスは本人限定のままにし、適切なサーバー側認証で保護する。公開HTMLに認証トークンを埋めない。固定時刻や世代情報が取得できるなら、別の監査用JSONに含めてもよい（CSV自体の形式は変更しない）。

## GitHub側で必要な設定
リポジトリの Settings → Secrets and variables → Actions → Repository secrets に次を設定する。

- `SITE_FIXED_CSV_URL`: 上のSite専用CSVエクスポートURL（**実際に作成・確認されたもの**を指定。URLを推測しない）。
- `SITE_EXPORT_AUTH`: そのSiteの所有者アクセスに使用する適切なAPI認証ベアラートークン。未使用の場合は空欄でもよいが、**サイトを認証なしで公開しない**。

`SITE_EXPORT_AUTH` は GitHub Actions 実行時のみ `OAI-Sites-Authorization` ヘッダーに渡す。HTTPリダイレクトは禁止し、送信先はHTTPSの `*.chatgpt.site` に限定する。

## 動作時刻
月・木 18:40 JST のスケジュール。GitHubのscheduleは数分以上遅延する場合がある。手動起動はActions → Sync Site Analyzer fixed tickets → Run workflow。

## 取込先
`comparisons/loto6-<開催回>-fixed-5tickets.csv`

5口の内容が正しいことを検証したうえで、`GITHUB_TOKEN` で新規ファイルだけをコミット。既存ファイルが同一内容なら何もしない。異なる場合は停止し、予想改ざん・不一致を検出する。比較ダッシュボードの `comparisons/**` push トリガーが続いて動く。ただしGitHub ActionsのGITHUB_TOKENによるpushは通常新しいworkflowを起動しないため、ダッシュボードは次回の時刻更新（毎時35分）で反映する。

## 注意
固定元CSVに固定日時・モデル世代が含まれていないため、自動取得できても固定時刻の証拠にはならない。比較画面では引き続き「未確認」と表示する。事前予測としての厳密な評価には、Site側で固定時刻・版番号などを署名付きまたは不可変ログへ記録する改善が必要。
