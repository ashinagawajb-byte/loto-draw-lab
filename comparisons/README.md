# Site Analyzer × DRAW LAB の5口比較データ

## 推奨：Analyzerから出力したCSVをそのまま保存

Site Analyzerが出力する **`loto6-2157-fixed-5tickets.csv`** と同じ形式に直接対応しました。次回も `loto6-2158-fixed-5tickets.csv` のように開催回番号を変えた原本CSVを `comparisons/` に保存するだけで取り込み対象になります。

```csv
回,口,数字1,数字2,数字3,数字4,数字5,数字6
2157,1,16,21,33,34,38,40
2157,2,5,14,24,32,35,43
2157,3,7,10,20,23,31,42
2157,4,1,3,4,6,27,37
2157,5,2,9,13,18,26,28
```

- UTF-8/BOM付きUTF-8の両方に対応。変換・リネームや英語の列名への編集は不要。
- 原本にない固定時刻・モデル世代は `未記載` / `未確認` と表示。GitHubに保存された時刻は原本が固定された時刻の証明とは別です。
- 5口の重複、欠落、数字の範囲外、開催回のファイル名との不一致は取り込みエラーにします。
- 発表済み結果との比較は可能ですが、**固定日時の証拠がない予測は事前固定済みの検証件数と区別**します。

## 旧形式（固定時刻と世代を持つ追加記録）


このフォルダに **事前固定した** Analyzer の予想5口を書き出した `analyzer_frozen.csv` を置くと、研究ダッシュボードでDRAW LABの固定5シード予想と並列に採点できます。Siteの認証領域に直接アクセスできない場合にも、過去の予想数字を推測せず比較するための取り込み口です。

CSV の必須列（順序は任意）：

```csv
round,draw_date,locked_at_jst,model,generation,ticket,n1,n2,n3,n4,n5,n6
```

- 1行=1口。同じ開催回/モデル/世代につき **1〜5口すべて**必要です。
- `draw_date`: `YYYY-MM-DD`。 `locked_at_jst`: `2026-11-23T18:20:00+09:00` のようなJSTオフセット付きISO形式。
- Site既存の固定記録の時刻をそのまま記載すること。未記録・後付けの時刻を捏造しない。
- 月木18:30 JSTより後に固定された記録は本番比較に取り込まず、研究用の過去検証データと区別する。
- `model` と `generation` にAnalyzerの方式名とモデル世代を記録する。
- 数字は1〜43の6個で重複なし。1組の5口も同一組合せの重複を認めない。
- Analyzerの30数字候補は入力不要。30数字包含率は別の研究欄として今後比較可能。
- 当選数字は`data/loto6.csv`から読み取り、固定済み記録だけを採点する。**採点のための過去データを未来の予想作成に使用しない**。
- 5口比較指標：最大本数字一致数、5口一致数合計、5等/4等/3等以上有無（ボーナスは等級判定のみに使用）。
- SHA256などの追加証跡がある場合、元のSiteエクスポートも別途保管しCSVが改変されていないことを検証する。CSVの固定時刻欄は元記録の真偽を技術的には証明できないため、固定日時の出典を必ず保持する。

現時点の固定DRAW LAB予想：`predictions/loto6_2157_2026-11-23.json`。このファイルは書き換えない。

取り込み例は意図的に**空欄**としている。実際のAnalyzer予想を取得できるまで架空の数字を登録しない。
